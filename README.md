КАК ЗАПУСТИТЬ ПРОЕКТ

У нас есть два режима запуска: режим разработки (рекомендуемый для каждого дня) и полный запуск в Docker.
 
Полный запуск в Docker (Проверка "как на сервере")
Этот режим собирает и запускает вообще всё (включая Java и Node.js) внутри контейнеров. Используется редко, чтобы проверить, что проект соберется с нуля.

Выполни в терминале в корне проекта:
docker compose --profile full up --build

Чтобы остановить — нажми Ctrl + C в терминале.

КАК ПРОВЕРИТЬ, ЧТО ВСЁ РАБОТАЕТ

Бэкенд:

Открой в браузере: http://localhost:8080/swagger-ui.html — должна открыться страница Swagger с документацией API.

Если открыть просто http://localhost:8080, должна быть страница с ошибкой 404 или 403

Фронтенд:

Открой в браузере: http://localhost:4200 — должна загрузиться стартовая страница.

Открой консоль браузера (F12). Если там нет красных ошибок — фронт успешно связался с бэком.

Базы данных:

Выполни команду docker compose ps. Ты должен увидеть статусы "Up" для контейнеров postgres и redis.

ПОЛЕЗНЫЕ КОМАНДЫ

Docker (выполнять в корне проекта):

docker compose ps — посмотреть, какие контейнеры сейчас работают.

docker compose logs -f backend — смотреть логи бэкенда в реальном времени (очень помогает искать ошибки).

docker compose logs -f frontend — смотреть логи фронтенда.

docker compose down — остановить все контейнеры (данные в БД сохранятся).

docker compose down -v — остановить всё и УДАЛИТЬ базу данных (полный сброс).

Для Бэкенда (из папки backend):

mvn clean install — собрать проект, скачать зависимости и прогнать тесты.

mvn clean package -DskipTests — быстро собрать проект (JAR-файл) без запуска тестов.

mvn spring-boot:run — запустить приложение из консоли.

Для Фронтенда (из папки frontend):

npm install — установить все зависимости (пакеты) из package.json.

npm run dev — запустить сервер разработки.

npm run build — собрать оптимизированную production-версию (создаст папку dist).

Работа с базой данных (PostgreSQL):

docker compose exec postgres psql -U tracker -d tracker — зайти в консоль БД (внутри писать SQL-запросы, \dt — показать таблицы, \q — выйти).
